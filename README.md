# 📝 Register Page

A clean and modern **Registration Page** built using **HTML** and **Bootstrap 5** with a two-column layout — image on the left and sign-up form on the right.

## 📸 Screenshot

![Register Page Screenshot](assets/img/screenshots/register-page.png)

## 📸 Preview

A split-layout registration card with a cover image, overlay text, and a clean white form panel for user sign-up.

## 🚀 Features

* Responsive two-column layout using Bootstrap 5 Grid
* Left panel with cover image and overlay text
* Right panel with sign-up form
* Full Name, Email, Username, Password, Confirm Password fields
* Terms of Use checkbox
* Clean card UI with rounded corners and shadow

## 🛠️ Technologies Used

* HTML5
* CSS3
* Bootstrap 5.0.2
