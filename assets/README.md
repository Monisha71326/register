# 📝 Register Page

A clean and modern **Registration Page** built using **HTML**, **Bootstrap 5** with a two-column layout — image on the left and sign-up form on the right.

## 📸 Preview

A split-layout registration card with a cover image, overlay text, and a clean white form panel for user sign-up.

## 🚀 Features

- Responsive two-column layout using Bootstrap 5 Grid
- Left panel with cover image and overlay text
- Right panel with sign-up form
- Full Name, Email, Username, Password, Confirm Password fields
- Terms of Use checkbox
- Clean card UI with rounded corners and shadow

## 🛠️ Technologies Used

- HTML5
- CSS
- Bootstrap 5.0.2

## ⚙️ Setup & Usage

1. **Clone the repository**
   ```bash
   git clone https://github.com/Monisha71326/your-repo-name.git
   ```

2. **Navigate to the project folder**
   ```bash
   cd your-repo-name
   ```

3. **Open `register.html` in your browser**
   ```bash
   open register.html
   ```
   or simply double-click the `register.html` file.

> ⚠️ Make sure the images exist at the correct paths:
> - `im.jpeg` — body background
> - `assets/img/img.jpeg` — left panel cover image

## 📌 Notes

- The project uses both a **local Bootstrap CSS** and a **CDN version** — you can remove the local one if not needed.
- The left panel overlay text uses `position-absolute` — adjust `start-25` class if alignment looks off on different screen sizes.
